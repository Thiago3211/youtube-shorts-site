Política de Privacidade

O Curiosidades do Mundo Shorts Agent é uma ferramenta de automação para publicação de vídeos no YouTube.

Permissões

O aplicativo solicita autorização OAuth para enviar vídeos ao canal do YouTube autorizado pelo usuário.

Uso de dados

As credenciais de autenticação são utilizadas para executar as operações autorizadas na API do YouTube.

Revogação de acesso

O usuário pode revogar o acesso do aplicativo nas configurações de segurança da sua Conta Google.
